# The Widening Edge

**Remoteness, Acceleration and the Connectivity Tax**: a code-driven working
paper.

> The equalisers of our age are also the multipliers of distance.

The paper argues that in an integrated, fast-moving world, remoteness stops
being a one-off cost and becomes a *recurring tax on participation*, paid on
every shipment, byte, specialist and negotiation, and that the taxes compound.
It tests the argument against public data and reports where the data cut
against it.

The repository is built like software. One command fetches every dataset,
computes every statistic, renders every figure and typesets a US Letter PDF.
**No number in the paper is typed by hand.** Prose numbers are LaTeX macros
generated by `scripts/export_stats.py`, and charts are pgfplots reading the
processed CSVs directly.

## Build

```bash
pip install .                 # pandas, wbgapi, geopandas, matplotlib, …
make all                      # fetch → process → stats → map → PDF
```

| Target | What it does |
|--------|--------------|
| `make data` | download raw sources (cached, idempotent), build remoteness index, process, export `generated/stats.tex` |
| `make figures` | render the Python map (`figures/remoteness_map.pdf`, vector) |
| `make pdf` | compile `paper/main.tex` with latexmk + LuaLaTeX + biber → `widening-edge.pdf` |
| `make final` | as `pdf`, but **fails if any `\placeholder{}` remains** |
| `make check-citations` | verify every DOI in `references.bib` against Crossref |
| `make clean` / `make distclean` | remove LaTeX outputs / also data caches and generated files |

Processed data, generated macros and the map are committed, so `make pdf` works
offline. The builds are deterministic: `SOURCE_DATE_EPOCH` is fixed, and raw
downloads are cached with SHA-256 checksums in `data/raw/MANIFEST.json`.
Fetching afresh may pull revised source data (the World Bank revises often).
CI reports any such drift with `git diff`.

**Requirements:** Python ≥ 3.10; TeX Live with LuaLaTeX, biber, latexmk,
`pgfplots`, `tcolorbox`, and the EB Garamond, Garamond-Math and Source Sans Pro
fonts (all in TeX Live; on Debian/Ubuntu, `texlive-luatex texlive-latex-extra
texlive-pictures texlive-fonts-extra texlive-bibtex-extra biber latexmk`).

## Layout

```
data/raw/            cached downloads (git-ignored) + MANIFEST.json (committed)
data/manual/         hand-curated narrative facts, each with a source URL
data/processed/      tidy CSVs read by LaTeX
data/SOURCES.md      every dataset: URL, access date, licence
scripts/fetch_*.py   one fetcher per source
scripts/build_remoteness.py   GDP-weighted distance to world output
scripts/process_*.py          clean/join → data/processed/
scripts/export_stats.py       → generated/stats.tex, regression and escape tables
scripts/make_map.py           → figures/remoteness_map.pdf
scripts/verify_citations.py   Crossref DOI check
paper/main.tex, preamble/, sections/, figures/, references.bib
.github/workflows/build.yml   CI: pipeline + compile + artifact (+ release on tag)
```

## Headline findings (from the current data)

- **Far, not small.** Distance carries the income penalty. Conditional on
  governance, doubling remoteness goes with about half the income per head;
  population barely matters, and being a small island adds no significant
  penalty.
- **Shipping at the edge stagnated** (median SIDS LSCI flat since 2006). The
  gap with the *old* hubs **narrowed**, though, which weakens the "widening"
  claim.
- **Internet access converged** sharply, so leapfrogging is real. Fixed
  broadband and cable redundancy did not.
- **Brain drain:** the median small island state lost over half its graduates
  to the OECD by 2010.
- **Who escapes:** Iceland and the Faroes are among the *least* remote
  economies by this measure. They are small, not far.
